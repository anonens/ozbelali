# Өзбекәлі және Мәдени майдан

351 беттік электронды кітап. Іздеу, қаріп пен жол аралығын өзгерту, үш түсті режим, бетбелгілер және соңғы оқу орнын осы браузерде сақтау бар.

## Іске қосу

```sh
python3 -m http.server 8000 --directory dist
```

Содан кейін http://localhost:8000 ашыңыз. Қосымша тәуелділік немесе build қадамы қажет емес.

## Vercel

Framework: Other. Build command: бос. Output directory: dist.

## Мазмұн

Мәтін пайдаланушы ұсынған PDF сканынан автоматты түрде танылды. Тану қателері болуы мүмкін. Барлық 351 беттің суреті «Түпнұсқа» режимінде қолжетімді. Нөмірлер цифрлық PDF беттеріне сәйкес келеді.

Кітаптың авторлық құқықтары құқық иелеріне тиесілі.
